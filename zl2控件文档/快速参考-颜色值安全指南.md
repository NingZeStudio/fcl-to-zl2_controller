# ZL2 控件系统 - 颜色值安全指南

## 🚨 紧急提示

**如果你的控件导入后崩溃，99%是颜色值问题！**

---

## ✅ 安全的颜色值（可以直接使用）

```json
{
  "backgroundColor": -9223372036854775808,
  "pressedBackgroundColor": -5510004026390872064,
  "contentColor": -4294967296,
  "pressedContentColor": -4294967296,
  "borderColor": -4294967296,
  "pressedBorderColor": -4294967296
}
```

### 颜色说明

| 颜色值 | 说明 | 用途 |
|--------|------|------|
| `-9223372036854775808` | 半透明黑色 | 最常用的背景色 |
| `-5510004026390872064` | 灰色 | 按下时的背景色 |
| `-4294967296` | 白色 | 文字和边框颜色 |

---

## ❌ 常见错误

### 错误1：使用随意的Long值
```json
// ❌ 错误！会崩溃
"backgroundColor": -16776961,
"contentColor": -1
```

### 错误2：使用十六进制ARGB
```json
// ❌ 错误！这不是Compose Color格式
"backgroundColor": 0xFF000000,
"contentColor": 0xFFFFFFFF
```

### 错误3：使用在线转换工具
```json
// ❌ 错误！在线工具生成的值不兼容
"backgroundColor": -16777216
```

## 🔧 快速修复方法

### 方法1：全局替换（推荐）

在你的JSON文件中，查找并替换所有颜色值：

```bash
# 替换所有背景色
查找: "backgroundColor": [任意数字]
替换为: "backgroundColor": -9223372036854775808

# 替换所有按下背景色
查找: "pressedBackgroundColor": [任意数字]
替换为: "pressedBackgroundColor": -5510004026390872064

# 替换所有内容色
查找: "contentColor": [任意数字]
替换为: "contentColor": -4294967296

# 替换所有按下内容色
查找: "pressedContentColor": [任意数字]
替换为: "pressedContentColor": -4294967296

# 替换所有边框色
查找: "borderColor": [任意数字]
替换为: "borderColor": -4294967296

# 替换所有按下边框色
查找: "pressedBorderColor": [任意数字]
替换为: "pressedBorderColor": -4294967296
```

### 方法2：使用示例文件

直接使用提供的 `example_control_layout_fixed.json` 作为模板。

## 💡 调整颜色的正确方法

### 方法1：修改透明度（推荐）

```json
{
  "alpha": 0.8,              // 80%不透明度
  "pressedAlpha": 1.0,       // 100%不透明度
  "backgroundColor": -9223372036854775808,  // 保持颜色值不变
  "pressedBackgroundColor": -5510004026390872064
}
```

### 方法2：使用ZL2编辑器

1. 在ZL2中打开控件编辑器
2. 使用可视化颜色选择器
3. 导出布局
4. 复制生成的颜色值

### 方法3：混合使用安全颜色

通过调整不同颜色的透明度来创建视觉效果：

```json
// 深色半透明背景
{
  "alpha": 0.7,
  "backgroundColor": -9223372036854775808
}

// 浅色半透明背景
{
  "alpha": 0.5,
  "backgroundColor": -5510004026390872064
}
```
