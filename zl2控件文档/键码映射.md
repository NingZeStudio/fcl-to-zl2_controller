## 7. FCL 到 ZL2 键码转换

### 数字键码到 GLFW 字符串

FCL 使用数字键码，ZL2 使用 `GLFW_KEY_*` 字符串格式。

转换时需要在 `src/converter/keymap.ts` 中维护映射表：

```typescript
const FCL_TO_GLFW: Record<number, string> = {
  // 字母
  30: 'GLFW_KEY_A',  // A
  48: 'GLFW_KEY_B',  // B
  // ... 等等
};

// 或反向映射
const GLFW_TO_FCL: Record<string, number> = {
  'GLFW_KEY_A': 30,
  'GLFW_KEY_B': 48,
  // ... 等等
};
```

## 8. 示例用法

```json
// ZL2 控件配置中的按键事件
{
    "clickEvents": [
        {
            "type": "key",
            "key": "GLFW_KEY_ESCAPE"
        }
    ]
}

// 鼠标按钮事件
{
    "clickEvents": [
        {
            "type": "launcher_event",
            "key": "GLFW_MOUSE_BUTTON_LEFT"
        }
    ]
}
```
