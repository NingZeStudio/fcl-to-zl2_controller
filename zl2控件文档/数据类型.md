# ZL2 控件系统 - 数据类型文档

> 来源: `e:\project\ZalithLauncher2\LayerController\src\main\java\com\movtery\layer_controller\data\`

## 1. ButtonPosition (按钮位置)

```kotlin
@Serializable
data class ButtonPosition(
    @SerialName("x") val x: Int,  // 范围 0~10000
    @SerialName("y") val y: Int  // 范围 0~10000
)
```

- **坐标系**: 万分比 (0-10000)，左上角为 (0, 0)，右下角为 (10000, 10000)
- **百分比计算**: `xPercentage = x / 10000f`

## 2. ButtonSize (按钮大小)

```kotlin
@Serializable
data class ButtonSize(
    @SerialName("type") val type: Type,              // Dp / Percentage / WrapContent
    @SerialName("widthDp") val widthDp: Float,        // 绝对值宽度，最小 5dp
    @SerialName("heightDp") val heightDp: Float,      // 绝对值高度，最小 5dp
    @SerialName("widthPercentage") val widthPercentage: Int,   // 100~10000
    @SerialName("heightPercentage") val heightPercentage: Int, // 100~10000
    @SerialName("widthReference") val widthReference: Reference,  // ScreenWidth / ScreenHeight
    @SerialName("heightReference") val heightReference: Reference
)
```

### 尺寸类型 (Type)
| 值 | 说明 |
|---|---|
| `dp` | 以 Dp 绝对值存储 |
| `percentage` | 以百分比值存储 |
| `wrap_content` | 跟随内容大小变化 |

### 参考尺寸 (Reference)
| 值 | 说明 |
|---|---|
| `screen_width` | 参考屏幕宽度 |
| `screen_height` | 参考屏幕高度 |

### 范围限制
- `MIN_SIZE_DP = 5.0f` (最小绝对尺寸)
- `SIZE_PERCENTAGE = 100.0f..10000.0f` (百分比范围)
- 编辑器可用: `SIZE_PERCENTAGE_EDITOR = 1.0f..100.0f`

### StyleConfig (样式配置)

```kotlin
data class StyleConfig(
    @SerialName("alpha") val alpha: Float,                    // 整体不透明度 0.0f~1.0f
    @SerialName("pressedAlpha") val pressedAlpha: Float,      // 按下时不透明度 0.0f~1.0f
    @SerialName("backgroundColor") val backgroundColor: Color,           // 背景颜色
    @SerialName("pressedBackgroundColor") val pressedBackgroundColor: Color, // 按下时背景颜色
    @SerialName("contentColor") val contentColor: Color,                // 内容颜色
    @SerialName("pressedContentColor") val pressedContentColor: Color,  // 按下时内容颜色
    @SerialName("fontSize") val fontSize: Int?,               // 文字大小 2~30
    @SerialName("pressedFontSize") val pressedFontSize: Int?, // 按下时文字大小
    @SerialName("borderWidth") val borderWidth: Int,          // 边框宽度 0~50
    @SerialName("pressedBorderWidth") val pressedBorderWidth: Int,      // 按下时边框宽度
    @SerialName("borderColor") val borderColor: Color,         // 边框颜色
    @SerialName("pressedBorderColor") val pressedBorderColor: Color,     // 按下时边框颜色
    @SerialName("borderRadius") val borderRadius: ButtonShape, // 圆角
    @SerialName("pressedBorderRadius") val pressedBorderRadius: ButtonShape
)
```

### 样式范围限制
| 属性 | 最小值 | 最大值 |
|------|--------|--------|
| alpha | 0.0f | 1.0f |
| fontSize | 2 | 30 |
| borderWidth | 0 | 50 |

## 4. ButtonShape (圆角形状)

```kotlin
@Serializable
data class ButtonShape(
    @SerialName("topStart") val topStart: Float,     // 左上角
    @SerialName("topEnd") val topEnd: Float,         // 右上角
    @SerialName("bottomEnd") val bottomEnd: Float,   // 右下角
    @SerialName("bottomStart") val bottomStart: Float // 左下角
): Modifiable<ButtonShape>
```

- **构造函数**: `ButtonShape(size: Float)` - 四角相同圆角
- **有效范围**: `SHAPE_RANGE = 0.0f..100.0f`

## 6. NormalData (普通按钮数据)

```kotlin
@Serializable
data class NormalData(
    @SerialName("text") val text: TranslatableString,        // 显示文本
    @SerialName("uuid") val uuid: String,                    // 唯一标识
    @SerialName("position") val position: ButtonPosition,   // 位置
    @SerialName("buttonSize") val buttonSize: ButtonSize,    // 大小
    @SerialName("buttonStyle") val buttonStyle: String?,      // 样式 UUID 引用
    @SerialName("textAlignment") val textAlignment: TextAlignment, // 文本对齐
    @SerialName("textBold") val textBold: Boolean,           // 加粗
    @SerialName("textItalic") val textItalic: Boolean,       // 斜体
    @SerialName("textUnderline") val textUnderline: Boolean, // 下划线
    @SerialName("visibilityType") val visibilityType: VisibilityType,
    @SerialName("clickEvents") val clickEvents: List<ClickEvent>, // 点击事件列表
    @SerialName("isSwipple") val isSwipple: Boolean,         // 滑动联动
    @SerialName("isPenetrable") val isPenetrable: Boolean,   // 触摸穿透
    @SerialName("isToggleable") val isToggleable: Boolean    // 开关模式
): Widget
```

### 交互属性
| 属性 | 说明 | FCL 对应 |
|------|------|----------|
| `isSwipple` | 滑动可与周围按钮联动操作 | - |
| `isPenetrable` | 允许触摸事件向下穿透 | `pointerFollow` |
| `isToggleable` | 以开关形式切换按下状态 | `autoKeep` |

## 颜色值 (Color)

颜色使用 Compose Color，以 Long 整数形式序列化（高 32 位为 ARGB）。

### 安全颜色值
| 用途 | ZL2 值 |
|------|--------|
| 背景色 | `-9223372036854775808` |
| 按下背景色 | `-5510004026390872064` |
| 文字/边框色 | `-4294967296` |

### 颜色序列化
```kotlin
// ColorSerializer.kt
object ColorSerializer : KSerializer<Color> {
    override val descriptor = PrimitiveSerialDescriptor("ColorAsLong", PrimitiveKind.LONG)
    override fun serialize(encoder: Encoder, value: Color) {
        encoder.encodeLong(value.value.toLong())
    }
    override fun deserialize(decoder: Decoder): Color {
        val longValue = decoder.decodeLong()
        return Color(longValue.toULong())
    }
}
```

## 默认值

| 类型 | 默认值 |
|------|--------|
| `DefaultButtonStyleConfig` | 半透明黑色背景，白色内容，无边框，全圆角 |
| `DefaultSize` | Percentage 类型，1400 百分比，参考屏幕高度 |
| `EmptyTranslatableString` | default = "" |
