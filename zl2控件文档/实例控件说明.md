## 控件布局概览

这是一个完整的Minecraft游戏控制布局示例，包含了玩家在游戏中需要的所有基本操作。

### 布局结构
```
├── main_menu (主菜单层)
│   └── MENU按钮 - 控制其他层的显示/隐藏
├── movement (移动层)
│   └── 8方向移动按钮 (WASD + 组合键)
├── actions (动作层)
│   ├── 鼠标左键 (PRI)
│   ├── 鼠标右键 (SEC)
│   ├── Shift潜行 (开关按钮)
│   └── 空格跳跃
├── hotbar (快捷栏层)
│   └── 1-6数字键
└── function_keys (功能键层)
    ├── ESC键
    ├── E键 (背包)
    ├── F3键 (调试信息)
    ├── F5键 (视角切换)
    ├── T键 (聊天)
    ├── IME (输入法切换)
    ├── 滚轮向上
    └── 滚轮向下
```

## 使用指南

### 导入控件
1. 将 `example_control_layout.json` 复制到设备
2. 在ZL2启动器中选择"导入控件布局"
3. 选择该JSON文件
4. 导入成功后在控件列表中选择使用

### 自定义修改

#### 调整按钮位置
修改 `position` 字段：
```json
"position": {
  "x": 7500,  // 0-10000 (0%-100%)
  "y": 6500   // 0-10000 (0%-100%)
}
```

#### 调整按钮大小
修改 `buttonSize` 字段：
```json
"buttonSize": {
  "type": "percentage",
  "widthPercentage": 2000,   // 20%屏幕高度
  "heightPercentage": 1300,  // 13%屏幕高度
  "widthReference": "screen_height",
  "heightReference": "screen_height"
}
```

#### 修改按钮样式
1. 在 `styles` 数组中找到对应样式
2. 修改颜色值（Long类型）
3. 调整透明度（0.0-1.0）
4. 修改圆角半径

#### 添加新按钮
1. 复制现有按钮配置
2. 修改 `uuid`（必须唯一）
3. 调整位置和大小
4. 设置点击事件
5. 选择或创建样式

## 常见问题

### Q: 按钮太小/太大？
A: 修改 `buttonSize` 中的 `widthPercentage` 和 `heightPercentage` 值

### Q: 按钮位置不合适？
A: 修改 `position` 中的 `x` 和 `y` 值（0-10000）

### Q: 想要不同的颜色？
A: **⚠️ 重要警告**：不要随意修改颜色值！

**安全的做法**：
1. 只使用以下验证过的颜色值：
   - `-9223372036854775808` (半透明黑色)
   - `-5510004026390872064` (灰色)
   - `-4294967296` (白色)
2. 或者修改 `alpha` 值来调整透明度（0.0-1.0）
3. 或者在ZL2编辑器中使用可视化颜色选择器

**为什么不能随意改颜色值？**
- 颜色值是特殊编码的Long格式，不是普通的ARGB值
- 错误的颜色值会导致应用崩溃（ArrayIndexOutOfBoundsException）
- 必须使用Compose Color兼容的特定格式

### Q: 如何添加更多快捷栏按钮？
A: 复制现有快捷栏按钮，修改UUID、位置和按键代码

### Q: 移动按钮不够灵敏？
A: 检查 `isSwipple` 是否为 `true`，调整按钮间距

### Q: 导入后崩溃？
A: 最常见的原因是**颜色值格式错误**

**检查步骤**：
1. 查看崩溃日志是否包含 `ArrayIndexOutOfBoundsException`
2. 检查所有样式中的颜色值
3. 确保使用的是安全的颜色值（见上面的列表）
4. 使用 `example_control_layout_fixed.json` 作为参考

**修复方法**：
- 将所有颜色值替换为安全值
- 或者使用提供的 `example_control_layout_fixed.json` 文件

## 故障排除指南

### 问题：导入时崩溃，显示 ArrayIndexOutOfBoundsException

**完整错误信息**：
```
java.lang.ArrayIndexOutOfBoundsException: length=20; index=63
at androidx.compose.ui.graphics.Color.getColorSpace-impl(Color.kt:660)
```

**原因分析**：
这是因为JSON文件中使用了错误格式的颜色值。Compose的Color类使用特殊的ULong格式存储颜色，包含颜色空间信息。随意使用的Long数值会导致颜色空间索引越界。

**解决方案**：

#### 方案1：使用修复版文件（推荐）
直接使用 `example_control_layout_fixed.json`，这个文件已经修复了所有颜色值问题。

#### 方案2：手动修复颜色值
如果你已经修改了原文件，需要手动替换所有颜色值：

**查找并替换**：
```json
// 将所有背景色替换为安全值
"backgroundColor": -9223372036854775808
"pressedBackgroundColor": -5510004026390872064

// 将所有内容色替换为安全值
"contentColor": -4294967296
"pressedContentColor": -4294967296

// 将所有边框色替换为安全值
"borderColor": -4294967296
"pressedBorderColor": -4294967296
```

#### 方案3：从默认布局复制
1. 打开 `ZalithLauncher/src/main/assets/default_layout.json`
2. 复制其中的样式配置
3. 使用相同的颜色值

**预防措施**：
- ✅ 始终从默认布局或示例文件复制颜色值
- ✅ 使用ZL2编辑器的可视化颜色选择器
- ✅ 只修改 `alpha` 值来调整透明度
- ❌ 不要使用在线颜色转换工具生成的值
- ❌ 不要使用标准的ARGB十六进制值
- ❌ 不要自己编造Long数值

### 问题：某些按钮不显示

**检查清单**：
1. 样式UUID是否存在于styles数组中
2. 颜色值是否正确
3. alpha值是否为0（完全透明）
4. 按钮位置是否在屏幕范围内（0-10000）
5. 层级是否被隐藏（hide: true）

### 问题：按钮点击无反应

**检查清单**：
1. clickEvents数组是否为空
2. 事件类型和key是否正确
3. 是否被上层按钮遮挡
4. isPenetrable设置是否正确

## 技术细节：为什么颜色值这么特殊？

### Compose Color的内部表示

Compose使用ULong（无符号64位整数）来存储颜色，格式如下：

```
位 63-56: 颜色空间ID (0-63)
位 55-48: Alpha通道
位 47-32: Red通道
位 31-16: Green通道
位 15-0:  Blue通道
```

这不是简单的ARGB值，而是包含了颜色空间信息的编码格式。

### 为什么会崩溃？

当你使用错误的Long值时：
1. 系统尝试从值中提取颜色空间ID
2. 如果ID超出有效范围（0-19），就会访问颜色空间数组越界
3. 导致 `ArrayIndexOutOfBoundsException: length=20; index=63`

### 安全的颜色值是如何生成的？

这些值是通过Compose的Color构造函数正确生成的：
```kotlin
Color(0xFF000000) // 生成 -9223372036854775808
Color(0xFFFFFFFF) // 生成 -4294967296
```

直接使用这些生成的值是安全的，但不要尝试自己计算或转换。

## 开发建议

### 推荐的工作流程

1. **从模板开始**
   - 使用 `example_control_layout_fixed.json` 作为起点
   - 或者复制默认布局

2. **小步修改**
   - 每次只修改一个按钮或样式
   - 立即导入测试
   - 确认无误后再继续

3. **使用编辑器**
   - 优先使用ZL2内置的控件编辑器
   - 可视化操作更安全
   - 自动生成正确的颜色值

4. **版本控制**
   - 保存每个工作版本
   - 出问题时可以快速回退

5. **测试验证**
   - 在不同屏幕尺寸上测试
   - 测试所有按钮功能
   - 检查不同场景下的显示

### 不推荐的做法

- ❌ 直接编辑复杂的JSON（容易出错）
- ❌ 从其他项目复制颜色值（格式可能不兼容）
- ❌ 使用在线工具生成颜色（格式错误）
- ❌ 一次性修改大量内容（难以定位问题）
