# ZL2 控件系统 - 示例布局分析

> 来源: `e:\project\ZalithLauncher2\ZalithLauncher\src\main\assets\default_layout.json`

## 1. 布局概述

这是 ZL2 启动器的默认控件布局文件，名为"默认"(default)，作者为"墨北MovTery"。

### 基本信息

```json
{

        "name": { "default": "default", "matchQueue": [{ "language_tag": "zh", "value": "預設" }, { "language_tag": "zh-CN", "value": "默认" }] },
        "author": { "default": "MovTery", "matchQueue": [{ "language_tag": "zh", "value": "墨北MovTery" }] },
        "description": { "default": "", "matchQueue": [] },
        "versionCode": 0,
        "versionName": "1.0"
    }
}
```

**用途**: 用于切换其他图层的显示状态

```json
{

    "position": { "x": 10000, "y": 0 },
    "buttonSize": {
        "type": "percentage",
        "widthDp": 50.0,
        "heightDp": 50.0,
        "widthPercentage": 2289,
        "heightPercentage": 1100,
        "widthReference": "screen_height",
        "heightReference": "screen_height"
    },
    "buttonStyle": "cac8c754ffa0",
    "visibilityType": "always",
    "clickEvents": [
        { "type": "switch_layer", "key": "b7859a69d0d3" },
        { "type": "switch_layer", "key": "9cad88ccdb1c" },
        { "type": "switch_layer", "key": "81548d8b5adb" },
```

## 5. move 图层分析 (WASD 移动)

**用途**: 游戏内移动控制，使用滑动联动 (isSwipple) 实现摇杆效果

### W+A 按钮 (左上)

```json
{
    "text": { "default": "◤", "matchQueue": [] },
    "position": { "x": 794, "y": 5411 },
    "buttonSize": {
        "type": "percentage",
        "widthPercentage": 1380,
        "heightPercentage": 1380,
        "widthReference": "screen_height",
        "heightReference": "screen_height"
    },
    "clickEvents": [
        { "type": "key", "key": "GLFW_KEY_W" },
        { "type": "key", "key": "GLFW_KEY_A" }
    ],
    "isSwipple": true
}
```

### W 按钮 (上)

```json
{
    "text": { "default": "▲", "matchQueue": [] },
    "position": { "x": 1474, "y": 5410 },
    "clickEvents": [{ "type": "key", "key": "GLFW_KEY_W" }],
    "isSwipple": true
}
```

### W+D 按钮 (右上)

```json
{
    "text": { "default": "◥", "matchQueue": [] },
    "position": { "x": 2154, "y": 5410 },
    "clickEvents": [
        { "type": "key", "key": "GLFW_KEY_W" },
        { "type": "key", "key": "GLFW_KEY_D" }
    ],
    "isSwipple": true
}
```

**特点**:
- 8 个方向按钮覆盖 WASD 四个方向及其组合（斜向）
- `isSwipple: true` 允许手指滑动时连续触发多个按钮
- 按钮排列成正方形布局，模拟虚拟摇杆

## 7. 坐标转换参考

### FCL 到 ZL2

| FCL 坐标 | ZL2 坐标 | 计算 |
|----------|----------|------|
| 0 | 0 | 0 * 10 |
| 100 | 1000 | 100 * 10 |
| 500 | 5000 | 500 * 10 |
| 1000 | 10000 | 1000 * 10 |

## 8. 尺寸转换参考

### FCL 百分比到 ZL2

FCL 尺寸为屏幕百分比 (0-100)，ZL2 为万分比 (0-10000)。

| FCL 尺寸 | ZL2 尺寸 | 计算 |
|----------|----------|------|
| 1% | 100 | 1 * 10 * 10 |
| 10% | 1000 | 10 * 10 * 10 |
| 22.89% | 2289 | 22.89 * 100 |
| 50% | 5000 | 50 * 100 |

## 9. 重要发现

### 1. 坐标系统差异
- ZL2 使用万分比 (0-10000)，而 FCL 使用千分比 (0-1000)
- 转换时需要乘以 10

### 2. 按钮组合键
- ZL2 支持单个按钮绑定多个键码
- 这在 FCL 中需要多个按钮实现

### 3. 滑动联动 (Swipple)
- 通过 `isSwipple: true` 实现虚拟摇杆效果
- FCL 的方向键可转换为带此属性的 ZL2 按钮组

### 4. 图层切换
- 使用 `switch_layer` 事件类型
- key 值为目标图层的 UUID

### 5. 样式分离
- 每个样式有 lightStyle 和 darkStyle
- `commonStyle: false` 启用主题区分

### 6. 文本多语言
- 使用 TranslatableString 结构
- 支持语言标签匹配
